# Markdown 语法手册

Markdown 是一种**轻量级标记语言**，用简洁的纯文本符号表达文档格式，最终渲染为 HTML 页面。

---

## 基本语法规则

- **纯文本本质**：Markdown 文件就是 `.md` 纯文本，任何编辑器都能打开。
- **空行分段**：两段文字之间必须有一个空行，否则会被合并成一段。
- **换行**：行尾加两个空格 + 回车，或直接插入空行。
- **转义字符**：用 `\` 转义特殊符号，如 `\*` 显示星号本身。
- **HTML 兼容**：可以直接在 Markdown 中写 HTML 标签，大多数渲染器都支持。

!!! warning "最常见错误"
    标题 `#` 后面必须有一个空格，如 `## 标题`，否则不会被识别。

---

## 核心语法

### 标题

`#` 数量对应层级（1-6 级），`#` 后必须有一个空格。知识库场景建议不超过 3 级，层级过深会影响目录可读性。

---

### 文字格式

| 效果 | 写法 | 说明 |
| --- | --- | --- |
| **粗体** | `**粗体**` 或 `__粗体__` | 两侧各两个 `*` 或 `_` |
| *斜体* | `*斜体*` 或 `_斜体_` | 两侧各一个 `*` 或 `_` |
| ~~删除线~~ | `~~删除线~~` | 两侧各两个 `~` |
| `行内代码` | `` `行内代码` `` | 两侧反引号 |
| **粗斜体** | `***粗斜体***` | 三个 `*` |

---

### 列表

- **无序列表**：`-`、`*`、`+` 均可，建议统一用 `-`；子项缩进 2 空格。
- **有序列表**：`1.` 开头；实际数字不影响渲染结果，统一写 `1.` 方便插入条目。
- **嵌套**：子项缩进 2 或 4 空格，与父项对齐即可。

---

### 链接与图片

```markdown
# 链接
[显示文字](https://example.com)
[显示文字](https://example.com "鼠标悬停提示")

# 图片
![替代文字](图片路径或URL)
![替代文字](图片路径 "悬停提示")

# 引用式链接（长 URL 场景，保持正文整洁）
[显示文字][ref]
[ref]: https://example.com
```

---

### 代码

- **行内代码**：单反引号包裹，如 `` `git status` ``。
- **代码块**：三个反引号包裹，后跟语言名称开启语法高亮。
- 常用语言标识：`python`、`bash`、`yaml`、`markdown`、`json`、`verilog`、`systemverilog`

---

### 表格

**对齐方式：**

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |
```

---

### 引用块

```markdown
> 这是一段引用。
>
> 引用可以有多段，段间空行加 `>` 保持连续。
>
> > 嵌套引用，再加一层 `>`。
```

---

### 分割线

```markdown
---
```

三个或更多 `-`、`*`、`_`（独占一行）均可生成分割线。

---

### 任务列表

```markdown
- [x] 已完成项目
- [ ] 未完成项目
- [ ] 另一个待办
```

---

### 注释（HTML注释）

Markdown 本身没有统一的“官方注释语法”，最常用、兼容性最好的做法是用 HTML 注释：

```txt
<!-- 这是一条注释，不会在页面中显示 -->
```

## MkDocs Material 扩展语法

以下语法需要在 `mkdocs.yml` 中开启对应扩展才能生效。

### 提示框（需要 `admonition`）

```markdown
!!! note "说明"
    这是 note 提示框，**缩进 4 空格**。

!!! warning "注意"
    这是 warning 提示框。

!!! danger "危险"
    这是 danger 提示框。
```

常用类型：`note`、`info`、`tip`、`warning`、`danger`、`success`、`question`

### 可折叠提示框（需要 `pymdownx.details`）

```markdown
??? note "点击展开"
    默认折叠，点击展开内容。

???+ note "默认展开"
    默认展开状态。
```

### 脚注（需要 `footnotes`）

```markdown
这里是正文内容[^1]，另一处引用[^note]。

[^1]: 脚注内容，显示在页面底部。
[^note]: 脚注支持中文标识符。
```
