# WaveDrom 使用指南

## 1. 概述

WaveDrom 是一款可通过**简单文本描述**生成数字时序图/波形的工具，输出结果为 **SVG 格式图片**。

## 2. 文档参考路径

| 类型 | 链接 | 说明 |
|------|------|------|
| 官方文档 | <https://wavedrom.com/tutorial.html> | 基础教程，建议优先阅读 |
| 第三方教程 | <https://blog.csdn.net/qq_42446721/article/details/121857435> | 对官方文档的补充与说明，推荐配套参考 |

## 3. 插件说明及使用

### 3.1 安装步骤

在编辑器插件库中搜索 **WaveDrom**，找到作者为 `Borja Penuelas` 的插件安装即可。

### 3.2 快速示例

- 新建 `test.json` 文件，输入以下内容并保存：

    ```json
    {
      "signal": [
        { "name": "ck", "wave": "p..." },
        { "name": "Data", "wave": "x.345x]=.x", "data": ["head", "body", "tail", "data"] },
        { "name": "Request", "wave": "0.1..0|1.0" },
        { "name": "Acknowledge", "wave": "1.....|01." }
      ]
    }
    ```

- 生成波形图：
    - **方式 1**：点击编辑器侧边栏/工具栏的 WaveDrom 渲染图标
    - **方式 2**：快捷键 `Ctrl + K` → 再按 `Ctrl + D`

## 4. 语法规范
>
> 建议先通读官方教程（约 30–45 分钟），再结合下文速查。

### 4.1 单条波形基本结构

```json
{
  "name": "",      // 信号名称
  "wave": "",      // 波形字符序列
  "data": [],      // 多 bit 信号数据（配合占位符使用）
  "phase": 0,      // 相位调整（占空比）
  "period": 1,     // 周期数
  "node": ""       // 节点标记，用于 edge 连线
}
```

### 4.2 `wave` 字符含义

| 类别 | 字符 | 说明 |
|------|------|------|
| **通用** | `.` | 重复上一个字符 |
| | `=`、`2`-`9` | 占位符（数字对应不同颜色） |
| | `|` | Gap（间隔） |
| **时钟信号** | `p`/`P`/`n`/`N` | 默认一个周期的时钟 |
| | `h`/`H`/`l`/`L` | 另一种时钟表示 |
| **单 bit 信号** | `1`/`0` | 高/低电平 |
| | `x` | X 态（图中显示为阴影） |
| | `z` | 高阻态（中间电平） |
| | `u`/`d` | 弱 1 / 弱 0（虚线表示） |

### 4.3 多 bit 信号

需配合 **占位符**（如 `2`、`3`）与 `data` 数组使用，数组中元素按顺序对应占位符位置。

### 4.4 全局 `signal`

- 一个 JSON 文件中**必须有且仅有一个** `signal` 字段。
- 支持**嵌套结构**，可组织多个波形组。

## 5. 配置项（`config`，可选）

| 参数 | 说明 |
|------|------|
| `hscale` | 水平缩放比例，值 > 0 |
| `skin` | 布局主题 |
| `head` / `foot` | 顶部/底部区域显示内容 |
| `tick` / `tock` | 时间线标签（分别在线上/线间） |
| `every` | 每 N 个周期生效一次 |
| `text` | 标题文本（支持 SVG 文本标记） |

### 预定义文本样式

| 字号 | `h1` > `h2` > `h3` > `h4` > `h5` > `h6`（数字越小字体越大） |
|------|----------------------------------------------------------|
| 颜色 | `muted`、`warning`、`error`、`info`、`success` |

### SVG 文本属性

| 属性 | 说明 |
|------|------|
| `x`/`y` | 定义文本起始位置的横纵坐标 |
| `dx`/`dy` | 定义相对于前一个文本位置的水平和垂直偏移量 |
| `font-family` | 设置字体系列 |
| `font-size` | 定义字体大小 |
| `text-anchor` | 设置文本对齐方式（如 `start`、`middle`、`end`） |
| `fill` | 设置文本颜色 |
| `rotate` | 以指定角度旋转文本 |
| `letter-spacing` | 为文本字符设置字符间距 |
| `word-spacing` | 为文本单词设置单词间距 |

## 6. 信号连线（`edge`）

用于在波形或波形间增加箭头，更好地展示时序图中的关键信息：

### 弧线（信号间转移）

| 符号 | 说明 |
|------|------|
| `~` | 波浪线 |
| `~>` | 带箭头的弧线 |
| `<~>` | 双向弧线 |
| `~<~>` | 双向箭头弧线 |

### 直线（时间间隔）

| 符号 | 说明 |
|------|------|
| `-` | 直线 |
| `->` | 带箭头的直线 |
| `<->` | 双向直线 |
| `<-\|->` | 带间隔的双向直线 |
| `->\|->` | 带间隔的单向箭头直线 |
