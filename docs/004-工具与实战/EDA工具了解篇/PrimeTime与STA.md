# PrimeTime 与 STA

PrimeTime（PT）是 Synopsys 的静态时序分析（STA）工具，用于在不跑动态仿真的情况下，检查数字电路在目标工艺角、时钟约束和负载条件下是否满足时序要求。

## 1. 核心作用

- 时序签核：分析 setup/hold 是否收敛，是后端时序闭环和流片前签核的关键环节。
- 路径定位：输出最差路径（WNS/TNS 等）并定位瓶颈单元、网络与约束问题。
- 约束校验：检查 SDC 约束完整性与合理性，减少漏约束或误约束导致的假收敛。
- 多场景分析：支持多模式多角（MMMC）统一分析，更贴近真实芯片运行条件。

## 2. 常见输入与输出

- 输入：综合网表、标准单元库（.lib）、寄生参数（SPEF）、时序约束（SDC）。
- 输出：时序报告、违例路径、时钟树质量信息、约束覆盖与一致性检查结果。

## 3. 在验证/后端流程中的位置

- 前端验证关注“功能对不对”，PT 更关注“在目标频率下能不能稳定跑”。
- 在 P&R 各阶段（pre-CTS、post-CTS、post-route）都会反复调用 PT 做收敛分析。
- 最终签核通常以 PT 报告为主依据之一。

## 4. 一句话总结

PrimeTime 的本质是把“时钟、路径、延时、约束”统一到同一分析框架中，帮助团队判断设计是否满足可流片的时序质量。
