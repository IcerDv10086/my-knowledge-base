# 跨时钟域与设计规范

## 跨时钟域的定义

跨时钟域（Clock Domain Crossing，CDC）是指数字电路中信号在不同时钟域之间传递的过程。当设计中的不同模块或子系统使用各自独立的时钟源时，信号从一个时钟域传递到另一个时钟域就形成了跨时钟域问题。

时钟域由一个时钟信号驱动所有寄存器的区域构成。在同一个时钟域内，所有寄存器都使用相同的时钟边沿进行数据采样和数据更新。典型的时钟域特征包括：

- **时钟频率**：不同时钟域可能使用不同的时钟频率，如 50MHz、100MHz、200MHz 等
- **时钟相位**：时钟之间的相位关系可能固定或不确定
- **时钟来源**：可能来自不同的 PLL、晶振或内部时钟管理单元

**核心挑战：**

- **亚稳态（Metastability）**：跨时钟域的信号可能在目标时钟域中产生亚稳态，导致采样值不确定
- **数据丢失或重复**：快时钟域到慢时钟域可能出现数据丢失，慢时钟域到快时钟域可能出现数据重复采样
- **数据不一致**：多比特信号跨时钟域时，由于路径延迟不同可能导致数据不一致
