# 芯片CP测试学习

## 简介

CP测试（Chip Probing）也叫**Wafer Sort**(晶圆筛选)，是芯片**封装前**在晶圆上对每一颗裸片进行电性与功能筛选的测试，通过探针台接触芯片焊盘，筛除不良芯片，降低后续封装成本。

### 1. 组成

CP测试系统主要由以下组件构成：

| 组件 | 角色类比 | 核心功能与细节 |
| :--- | :--- | :--- |
| 测试机台 | “诊断医生” | **测试向量**转换成接口时序，执行 DC/AC/功能等测试 |
| 探针台 | “护士/助手” | 精确定位晶圆，移动卡盘，控制温度 |
| 探针卡 | “连接桥梁” | 物理接口，传输电信号，类型多样 |

### 2. 流程

CP测试的完整流程如下：

1. **晶圆上料**：将待测试的晶圆放置到探针台的卡盘上
2. **探针台定位**：精确定位晶圆位置，确保探针卡能准确接触芯片焊盘
3. **探针卡接触**：探针卡下降，探针与芯片焊盘建立物理接触
4. **测试机测试**：测试机发送测试向量，执行 DC/AC/功能等测试
5. **记录结果与生成晶圆图**：记录测试结果，并生成包含芯片良率分布的晶圆图
6. **移动下一芯片**：探针台移动到下一颗芯片位置，重复上述流程直到所有芯片测试完成

## 测试向量（Pattern）

### 1. Pattern 概念

测试机台加载测试向量文件后，根据文件的内容，控制芯片引脚信号，生成对应的时序波形驱动与采样，从而验证芯片的功能与时序。

- 不同**测试机台**（Advantest、Teradyne、Cohu）有专属 Pattern 格式，但原理一致
- 除了 pattern 测试向量文件外，还有如设置**测试机台频率、信号相位与占空比、采样时刻**等配置型文件

!!! note
    配置文件主要包括**参数定义文件**和 **wavetab** 文件，功能如下：
    - **引脚电平**：定义 IO 输入输出、电平、负载等参数
    - **时序规格**：设定周期（频率）、信号边沿等
    - **测试算法**：控制测试流程，如pattern加载的顺序、重复次数等，本质上是**C语言的脚本**
    - **其他参数**：如信号采样点、特殊模式等

### 2. 向量开发与转换流程

| 阶段 | 主要活动与角色 | 关键点 |
| :--- | :--- | :--- |
| 设计/仿真 | DFT工程师生成 VCD/EVCD 测试向量 | 标准事件格式，易读 |
| 格式转换 | 工具转为 WGL/STIL | 时序周期格式，便于机台处理 |
| 机台准备 | 导入 STIL/WGL，转为专用二进制 | 机台专用格式，直接执行 |

测试机台使用的标准向量格式只有以下两种：

- STIL：IEEE1450.x 标准测试向量格式
- WGL：传统工业界通用向量格式（.avcl / .pat）

### 3. 事件级 vs 时序级 Pattern

- **事件级向量（VCD/EVCD）**：描述信号变化，便于理解和修改
  优点：易读、易维护
  缺点：抽象层级高，编写复杂
- **时序级向量（WGL/STIL）**
  以时钟周期为单位，适合机台执行
  支持波形、时序、电压描述

数字团队先输出**事件级读写命令向量**，从本质上看是抽象后的事件级向量，再转换为**时序级向量**供测试使用；工程中常说的 Pattern 一般指**时序级向量**。

### 4. 时序 Pattern 格式

时序级 pattern 通常为如下格式：

```
FORMAT SS SCLK MISO MOSI IRQ;
R10 TEST 1 0 X 0 X #X; //wait WIPAD repeat 10 times=us/spi_pcr */
R1  TEST 1 0 X X H #H; //wait WIPAD H
R2  TEST 1 0 X 0 X; //Restart, repeat 2 times*
```

**头部声明**：`FORMAT SS SCLK MISO MOSI IRQ;` 定义每行信号顺序

**数据行说明**：

| 列号 | 内容 | 说明 |
| :--- | :--- | :--- |
| 第一列 | 循环次数标识 | 如 R10 表示此行重复 10 次 |
| 第二列 | 命令类型 | 如 TEST |
| 第三至第七列 | 信号值 | 依次对应 SS、SCLK、MISO、MOSI、IRQ，取值可为 0、1、X、H 等 |
| 第八列 | 特殊标记 | 如 #X、#H |
| 行尾 | 注释 | 说明该行作用，如等待信号、重复次数、重启等 |

### 5. 示例：SPI 模式与机台配置

某项目采用 SPI 协议，机台作为 SPI 主控，需支持 4 种标准模式及自定义 Highspeed 模式。不同模式下测试机台会加载对应配置文件。

**类型 1：SS\MOSI\SHUTDOWN：**

均为驱动信号，不同模式下标志含义一致，0/1 分别表示周期内为低/高。

**类型 2：IRQ：**

输出信号，采样时刻为 0.5cyc，H/L 分别表示高/低电平，X 为不检查。

**类型 3：SS_SCLK\MISO：**

SS_SCLK 为驱动信号，驱动依赖 SPI 模式，具体见下表：

| 标志 | SPI-MODE0/1+Highspeed | SPI-MODE2/3 |
| :--- | :--- | :--- |
| 0 | 周期内都为 0 | 周期内都为 1 |
| 1 | d1:0 d2:1 d3:0,**码型 010** | d1:1 d2:0 d3:1,**码型 101** |

MISO 为待检查信号，采样时刻与模式有关：

- SPI 模式 0、2 和 highspeed 模式为相位 d2
- SPI 模式 1、3 为相位 d3
- 标志含义参考 IRQ 信号

## 测试内容与顺序

### 1. 测试顺序

对于一个裸片，它的测试pattern通常按以下顺序执行，从简单到复杂，尽早发现缺陷：

1. 接触测试 ：验证探针与芯片焊盘的物理连接是否良好
2. DC测试（漏电/功耗） ：测量静态参数，如漏电流、静态电源电流（IDDQ）等
3. AC测试（时序） ：验证时序特性，包括引脚的传输延迟、建立/保持时间、最高工作频率
4. DFT/MBIST ：执行扫描链、ATPG 向量，覆盖制造缺陷
5. **功能测试** ：验证芯片在真实场景下的功能正确性

在工作实践中，在功能测试阶段，由数字验证团队提供针对**功能测试项**的测试向量。通常功能测试表通常由设计、验证、测试团队合作完成。

### 2. 其他说明

- **OTP烧录**：芯片含 OTP（一次性可编程），CP 阶段需烧录厂商 ID、电压、时钟校准等信息，烧录过程通常在 DC/AC 测试后、DFT/MBIST 前完成
- **时钟校准**：功能测试前已完成时钟校准
- **向量切换**：多项测试向量间，常用 shutdown 复位后，再切换功能 pattern
