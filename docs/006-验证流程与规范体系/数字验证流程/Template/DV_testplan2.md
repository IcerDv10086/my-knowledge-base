## 1. 概述

### 1.1 验证范围（In Scope）

描述本验证计划覆盖的内容：

- 验证的层次（模块级/子系统级/IP集成）
- 待验证模块/子系统的功能列表
- 重点关注的验证点

### 1.2 验证范围外（Out of Scope）

明确本验证计划**不**覆盖的内容：

- 不验证的功能或场景
- 其他团队或模块负责的验证项
- 不适用的验证类型（如后仿、Formal等）

### 1.3 验证策略

| 策略类型 | 说明 | 适用场景 |
|----------|------|----------|
| 黑盒验证 | 仅通过接口和规格进行验证，不关注内部实现 | 外部接口功能、协议一致性 |
| 白盒验证 | 基于设计内部实现进行验证 | 内部状态机、边界检查 |
| 灰盒验证 | 结合接口和部分内部信号进行验证 | 关键路径、内部错误检测 |
