# 数字模拟混合信号建模相关总结

> 来源：<https://www.cnblogs.com/cmyxjcc/p/19648848>
> 说明：本文为原文解析整理版，保留核心知识结构，便于在验证工作中快速检索。

## 1. 驱动强度（Drive Strength）

在多驱动网络中，仿真器不仅比较逻辑值（0/1/X/Z），也比较驱动强度，遵循“强胜弱”的决断原则。

常见强度从高到低：

- `supply`（最强）
- `strong`
- `pull`
- `weak`
- `highz`（高阻）

实战规则：

- 强驱动覆盖弱驱动。
- 同强度且逻辑冲突通常决断为 `X`（`wand`/`wor` 线网除外）。
- 通过电阻性器件（如 `rnmos`/`rtran`）会发生强度衰减。

## 2. 线网类型（Net Types）

SystemVerilog 线网类型可用于建模不同互连行为：

- `wire`/`tri`：通用互连。
- `wand`/`wor`：线与/线或，适合开漏等场景。
- `tri0`/`tri1`：带默认下拉/上拉行为。
- `trireg`：可建模电荷保持与衰减。
- `uwire`：单驱动检查，多驱动时报错。

## 3. 门级与开关级原语

常用原语分类：

- 基本门：`and`/`or`/`buf`/`not`
- 三态门：`bufif1`/`notif0`
- 双向传输门：`tran`/`tranif1`
- 上下拉：`pullup`/`pulldown`
- MOS 原语：`nmos`/`pmos`/`cmos`

## 4. 延时建模

常用延时写法：

- `#(min:typ:max)`：多工艺角延时
- `#(rise, fall, turn_off)`：按边沿分别建模

要点：

- 门级默认偏惯性延时（会过滤窄脉冲）。
- 混合建模时需明确何处需要“滤毛刺”，何处要求“无损传播”。

## 5. RNM 与用户自定义线网

核心能力：

- `nettype real` 可直接传输实数信号。
- 支持自定义 `resolution function` 处理多驱动决断（如电流求和）。
- `interconnect` 适合在顶层做类型中立连接。

示例（实数线网 + 求和决断）：

```systemverilog
function automatic real sum_resolver(input real drivers[]);
    real total = 0;
    foreach (drivers[i]) total += drivers[i];
    return total;
endfunction

nettype real current_net with sum_resolver;
```

## 6. 数模边界转换

纯数字 `logic/wire` 不能直接识别 `real`，边界处需要 A2D/D2A 转换。

示例：

```systemverilog
assign dig_out = (ana_in > 0.8) ? 1'b1 : 1'b0; // A2D
assign ana_out = dig_in ? 1.8 : 0.0;           // D2A
```

工程建议：

- 在 wrapper/interface 统一做边界转换。
- 模型内部保持高精度，对外接口类型清晰。

## 7. 调试技巧（VCS + Verdi）

- VCS：`+fsdb+strength=on` 开启强度信息 dump。
- Verdi：开启波形强度显示选项，便于排查多驱动冲突。

## 8. 适用场景速记

- GPIO 开漏、上下拉与冲突决断
- 简化数模接口行为建模
- real-number model（RNM）快速系统级验证
