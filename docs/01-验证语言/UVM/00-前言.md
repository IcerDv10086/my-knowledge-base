# UVM 总览

## 1. 写作目标

本系列主要分成两条线：

1. 从源码视角理解 UVM 的实现机制。
2. 结合项目实践，沉淀可直接复用的方法和脚本。

## 2. 希望达成的结果

- 理解 UVM 的整体架构和组件协作方式。
- 能够独立实现常见 UVM 组件与派生逻辑。
- 能够把 UVM 方法落到真实项目中，而不是停留在概念层。

## 3. 产出方向

- 自动化 UVM 框架脚本。
- 自动化 regmap / RAL 脚本。
- 可复用的验证工程模板。

## 4. 阅读建议

- 先看前言建立整体地图。
- 再按 factory、phase、sequence、TLM、reg model 的顺序阅读。
- 遇到项目实践案例时，优先关注“为什么这样设计”，其次再看代码细节。
