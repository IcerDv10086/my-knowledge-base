# LLM公司与产品梳理

根据2025-2026年的行业动态，全球大语言模型（LLM）领域已形成以中美为主导的竞争格局。

截至2025年8月，美国平台在全球访问量中仍占据约93%的份额，保持绝对优势。但中美顶尖大模型性能差距已从2024年1月的9.3%大幅收窄至2025年2月的1.7%。竞争路径呈现分野：美国依托高密度算力**深化规模扩展**，中国则在算力约束下**以架构优化追求单位算力效率**。以下内容夹带个人观点，有失偏颇，欢迎指正。

## 国内主要LLM公司及产品

中国大模型行业已从“百模大战”进入深度竞争阶段，形成了以字节、阿里、阶跃星辰、智谱AI和DeepSeek为代表的“新五强”格局，竞争焦点转向技术、商业落地、开源生态与国产算力的综合较量。

| 公司 | 代表模型/平台 | 核心特点 |
| :--- | :--- | :--- |
| **深度求索 (DeepSeek)** | DeepSeek R1、DeepSeek V3系列 | 技术标杆与开源先锋，数学推理和代码生成能力达国际前沿，坚持开源推动普惠 |
| **阿里巴巴** | 通义千问 (Qwen) 系列、百炼平台 | 开源生态强大，HuggingFace开源模型占比高，云基础设施完善 |
| **字节跳动** | 豆包大模型、火山方舟平台 | 商业规模领先，企业级Agent平台覆盖广，成本效率高 |
| **阶跃星辰** | Step系列大模型 | 多模态能力突出，超七成自研模型为多模态，商业化路径清晰 |
| **智谱AI** | GLM系列、CogAgent平台 | 技术性能与成本平衡，模型曾登顶全球榜单，商业化进展快 |
| **百度** | 文心一言 (ERNIE) 系列、千帆平台 | 中文理解与行业深耕，中文语义理解能力强，知识图谱庞大 |
| **华为** | 盘古大模型、昇腾AI | 国产全栈式方案，从芯片到云平台全栈自主，工业场景落地深 |
| **腾讯** | 混元大模型、腾讯云TI平台 | 生态场景融合，与社交办公生态无缝集成，支持实时推理 |
| **月之暗面 (Moonshot AI)** | Kimi系列 | 长上下文与低成本，Kimi K2支持128K token上下文 |
| **MiniMax** | MiniMax-01系列 | 强调低成本与开源，快速迭代发布新模型 |
| **百川智能** | Baichuan系列 | 开源模型代表，早期发布Baichuan-7B/13B等模型 |

### 深度求索 (DeepSeek)

- 技术进展：数学推理和代码生成能力达到国际顶尖水平，坚持开源策略推动AI普惠，持续优化训练和推理成本
- 产品布局：DeepSeek R1系列专注代码生成和数学推理，DeepSeek V3系列扩展多模态能力

### 阿里巴巴

- 技术进展：Qwen3系列采用MoE和Dense混合架构，支持轻量级设备部署和复杂推理任务，开源生态持续扩展
- 产品布局：通义千问(Qwen)系列覆盖通用场景，百炼平台提供企业级开发能力

### 字节跳动

- 技术进展：豆包大模型1.6支持视频生成，企业级Agent开发平台成熟，MoE架构优化推理成本
- 产品布局：豆包大模型面向C端和B端，火山方舟平台提供企业级服务

### 阶跃星辰

- 技术进展：多模态推理能力持续领先，智能终端Agent技术深耕
- 产品布局：Step系列大模型专注多模态方向

### 智谱AI

- 技术进展：GLM-4.5-Flash采用MoE架构，提供思考/非思考双推理模式，兼顾性能与成本
- 产品布局：GLM系列覆盖通用大模型场景，CogAgent平台支持智能助手开发

### 百度

- 技术进展：文心大模型4.5采用FlashMask动态注意力掩码，多模态异构专家技术应用，长文处理和多轮交互能力提升
- 产品布局：文心一言(ERNIE)系列提供通用大模型能力，千帆平台提供企业级服务

### 华为

- 技术进展：盘古NLP-N2-128K模型支持长文本处理，昇腾芯片+训练框架+云平台协同优化
- 产品布局：盘古大模型聚焦行业解决方案，昇腾AI提供基础设施服务

### 腾讯

- 技术进展：混元Turbo S在Chatbot Arena排名全球前八，实时推理性能优化
- 产品布局：混元大模型覆盖通用和垂直领域，腾讯云TI平台提供企业服务

### 月之暗面 (Moonshot AI)

- 技术进展：长上下文处理能力持续优化，Agent任务执行能力增强
- 产品布局：Kimi系列专注长文本处理场景

### MiniMax

- 技术进展：发布MiniMax-Text-01和MiniMax-VL-01模型，追求与国际领先模型竞争
- 产品布局：MiniMax-01系列提供通用大模型能力

### 百川智能

- 技术进展：Baichuan-7B/13B等模型广泛应用，支持中英文双语
- 产品布局：Baichuan系列提供开源大模型

## 国外主要大模型公司及产品

美国在私有投资与算力上占优势，其LLM生态以闭源和企业级应用为主。欧洲的Mistral AI则以高效开源模式突围。

| 公司 | 代表模型系列 | 核心特点 |
| :--- | :--- | :--- |
| **OpenAI** | GPT系列 | 行业领导者，对话同理心指标提升明显，代码生成和数据处理错误率大幅下降 |
| **Google (DeepMind)** | Gemini系列 | 综合实力强劲，以1501 Elo高分登顶LMARena排行榜，支持10M token超长上下文 |
| **Anthropic** | Claude系列 | 专注安全与长程推理，"宪法AI"架构确保合规性，专业领域表现卓越 |
| **Meta** | Llama系列 | 开源生态核心，Llama 4系列为多模态MoE模型，全球开发者广泛应用 |
| **xAI** | Grok系列 | 独特定位，Grok 4突破"人类最后考试"50%准确率，具备原生工具使用能力 |
| **NVIDIA** | Nemotron系列 | 从硬件到模型优化，Nemotron-3推理吞吐是GPT-4.5的3.2倍，逼近顶级编程模型性能 |
| **亚马逊云科技 (AWS)** | Nova系列、Mistral AI | 云服务与模型结合，提供自研和开源模型组合选择 |
| **Mistral AI** | Mistral系列 | 欧洲开源代表，高效、开放的模型著称，Mixtral 8x7B等模型被广泛采用 |

### OpenAI

- 技术进展：GPT-5.1在对话"同理心"指标上提升明显，智能路由技术优化模型选择，代码生成和数据处理能力持续进化
- 产品布局：GPT系列定义现代LLM标准，ChatGPT服务C端用户

### Google (DeepMind)

- 技术进展：Gemini 3.0多模态能力突破，超长上下文处理能力扩展，推理和编程能力持续优化
- 产品布局：Gemini系列提供多模态大模型能力，Bard提供对话产品服务

### Anthropic

- 技术进展：Claude Sonnet 4.5编码能力提升，长程推理能力突破，安全合规体系完善
- 产品布局：Claude系列专注安全优先的大模型应用

### Meta

- 技术进展：Llama 4系列多模态MoE架构，社区反馈驱动迭代优化
- 产品布局：Llama系列作为开源大模型标杆

### xAI

- 技术进展：Grok 4突破关键基准测试，原生工具使用能力增强
- 产品布局：Grok系列提供差异化大模型服务

### NVIDIA

- 技术进展：Nemotron-3推理优化突破，软硬件协同优化
- 产品布局：Nemotron系列专注推理专用模型

### 亚马逊云科技 (AWS)

- 技术进展：Nova 2系列模型发布（Light, Pro, Sonic, Omni），Mistral Large 3集成
- 产品布局：Bedrock平台提供模型即服务

### Mistral AI

- 技术进展：高效模型架构优化，开源生态持续扩展
- 产品布局：Mistral系列提供高效开源模型
